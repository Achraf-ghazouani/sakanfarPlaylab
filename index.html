IF YOU CAN SAY IT,
YOU CAN PLAY IT.

Introducing Sakanfar PlayLab, an experimental game lab where a chat, a pen and a phone are the game engine. Racing, puzzles, platformers, shooters, sports: say it or sketch it, and Meta's Muse Wonder writes the whole game as code. No coding, no templates.

1SAY IT

"A car race with 3 laps and 4 AI cars." Or sketch a 2D level on the pad, or show a drawing to your phone camera. Muse Spark turns it into a short plan you can change for free.

2AI CODES IT

Muse Wonder writes the whole game as code (Phaser or three.js), tests it in a sandbox, fixes its own bugs and looks at the result. Ask for changes in words: it patches the code in seconds.

3PLAY

Play on the keyboard, or turn up to four phones into controllers: each shows the pad the game asks for. Publish it, share the link, let friends remix it.
